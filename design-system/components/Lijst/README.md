# Lijst

Grote woorden in rijen, elk met een kleurvak en symbool rechts. Voor navigatie, diensten en stappen.

- Markup: `<div class="x8-lijst">` met `<a class="x8-rij"><span class="x8-rij__woord">Websites</span><span class="x8-rij__vak x8-k-oranje" data-symbool="pijl-rechts"></span></a>`.
- Het woord staat op `wit`, het vak in een tegelkleur. Hover kantelt het vak.
- Een woord per rij, maximaal zes rijen.
