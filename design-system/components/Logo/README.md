# Logo

Het officiële 2X8-logo en het beeldmerk, altijd uit het SVG-bestand.

- Logo: `<span class="x8-logo" data-logo></span>` en daarna `X8.mount()`. De hoogte volgt `font-size` (standaard 96px); `x8-logo--klein` is 28px voor navigatie en footer.
- `x8-logo--kalk` enkel op `petrol` of een foto.
- Beeldmerk: `<span class="x8-beeldmerk" data-beeldmerk></span>`: de X uit het logo op een `oranje` tegel. Grootte via `font-size`.
- Niet doen: het logo natypen, vervormen, inkleuren met een tegelkleur, of een schaduw geven.
