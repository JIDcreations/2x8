# Tegel

Het kernbeeld van het merk: een afgeronde kleurvlak met een dik zwart symbool en een woord onderaan.

- Markup: `<a class="x8-tegel x8-k-oranje"><span class="x8-tegel__symbool" data-symbool="pijl"></span><p class="x8-tegel__woord">Websites</p></a>`.
- Kleur via een `x8-k-*`-klasse: violet, oranje, petrol, limoen, hemel, salie, zon, leisteen of wit.
- Zet tegels altijd in een rij of raster met `space-1` tussen; een tegel staat nooit alleen.
- Een tegel, een kleur, een symbool, een woord. Geen zinnen op een tegel.
- Vaste koppeling voor diensten: Websites = oranje + pijl, Tools = hemel + ster, Automatisatie = salie + schakel, Hosting = petrol + cirkel, Strategie = violet + golf, Resultaat = limoen + pijl.
