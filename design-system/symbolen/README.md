Negen symbolen, getekend op een raster van 120, lijndikte 14, rechte uiteinden. De bestanden hier zijn in `inkt` (#181818).

- `pijl`: websites, groei, resultaat. `pijl-rechts`: verder, volgende stap.
- `ster`: tools en ideeën. `schakel`: automatisatie, dingen die verbinden. `golf`: strategie.
- `cirkel`: hosting, stabiliteit. `punt`: live, actief. `acht` en `kruis`: merkmomenten, nooit in de plaats van het logo.
- Zet ze enkel op een kleurtegel, in `inkt` (of `op-petrol` op petrol). In code via `X8.symbool(naam)`.
