# Widget

Kleine afgeronde tegels met een cijfer, in een bento-raster. Voor resultaten, rapporten en dashboards.

- Raster: `<div class="x8-bento">` (4 kolommen, gap `space-1`). Widgets: `.x8-widget` plus een kleurklasse; `x8-widget--breed` (2 kolommen) en `x8-widget--hoog` (2 rijen).
- Inhoud: `.x8-widget__label` (mono, bovenaan), `.x8-widget__getal` of `.x8-widget__tekst`, eventueel `.x8-widget__symbool`.
- Enkel echte cijfers. Een widget, een cijfer.
- Op gsm: 2 kolommen.
