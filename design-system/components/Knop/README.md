# Knop

Afgeronde knoppen in pilvorm.

- `.x8-knop`: hoofdactie, `kalk` op `inkt`. `.x8-knop--kleur`: oranje met inkt, voor de ene actie die moet opvallen (meestal contact). `.x8-knop--rand`: secundair.
- Een pijl-symbool mag achteraan: `<span class="x8-knop__symbool" data-symbool="pijl-rechts" data-dikte="18"></span>`.
- Tekst: een werkwoord in gewone zinsbouw. "Plan een gesprek", niet "KLIK HIER".
